# Sweet Potato Planet

Landing Page introducing handmade products, especially Scrunchies from Lang

## How To Run App

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the app in your browser:

```text
http://localhost:3000
```
